portfolio-site

This website. A portfolio that renders itself as the IntelliJ IDEA UI — project tree, editor tabs, gutter, status bar and all — because a plain landing page felt like a missed opportunity.

Stack

  • Spring Boot 3.5 / Java 21, built with Maven.
  • Thymeleaf with the layout dialect for the non-IDE surfaces.
  • A hand-rolled vanilla JavaScript shell — no framework, no jQuery.
  • One CSS file approximating the IntelliJ "New UI" dark theme.

How it works

  • The server renders the project tree from a ProjectStructure bean.
  • Opening a file fetch()es /content?path=…, which returns a Thymeleaf fragment that gets injected into a cached editor pane.
  • Open tabs, order, the active file, folder collapse state and panel width all live in localStorage; deep links use ?file=.
  • Tabs drag to reorder, close on middle-click or Ctrl/Cmd+W, and the gutter line numbers are generated to match content height.

Ideas still on the list
