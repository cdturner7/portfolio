portfolio-site

This website. A portfolio that renders itself as the IntelliJ IDEA UI — project tree, editor tabs, gutter, status bar and all — because a plain landing page felt like a missed opportunity.

Stack

  • Spring Boot 3.5 / Java 21, built with Maven.
  • Thymeleaf with the layout dialect for the non-IDE surfaces.
  • A hand-rolled vanilla JavaScript shell — no framework, no jQuery.
  • One CSS file approximating the IntelliJ "New UI" dark theme.

Features

  • Search Everywhere — press Shift twice for a fuzzy file‑and‑action finder; Ctrl/Cmd+Shift+A scopes it to actions.
  • Bottom tool window (Alt+F12) — tabbed: Problems, TODO (parsed live from TODO.md — click an item to open it), Git log, and a Terminal that types back (help, ls, cat, open, git log, resume and more, with ↑/↓ history).
  • Syntax highlighting — a small hand‑rolled tokeniser colours the code blocks in the Markdown “files” at runtime.
  • Skills.json — real JSON rendered as an IntelliJ‑style collapsible tree (per‑skill proficiency, category nodes fold on click, Collapse / Expand all).
  • notes/ — short build write‑ups on this project: the fake‑IDE shell, the dependency‑free JSON tree, and hash routing that keeps the Back button working.
  • On‑theme extras — CHANGELOG.md from the git history, dependencies.json (the real toolchain, in the tree viewer), and a shields‑style deploy badge on the README.
  • Now.md — a /now + /uses page: current focus, and the editor / build / cloud / shell tools behind the day‑to‑day.
  • Tagged experience — each role and the education entry carry a dated header and a row of tech tags, so Experience.md scans at a glance.
  • Structure view — the left dock switches (Alt+7) to an outline of the open file’s headings; click one to jump to it.
  • Settings dialog (Ctrl+Alt+S) — switch theme (Darcula / IntelliJ Light / high contrast), editor font size and line height, and a presentation mode that strips the chrome down to the editor.
  • Caret & go-to-line — click in the editor to move the caret (the status bar tracks line:column and the current line is highlighted); Ctrl+G jumps to a line.
  • Editor tabs — drag to reorder, middle‑click or Ctrl/Cmd+W to close, Ctrl/Cmd+Shift+←/→ to cycle.
  • Recent Files & breadcrumbs — Ctrl/Cmd+E pops up a most‑recently‑used file list (arrows or repeated Ctrl/Cmd+E to move, ↵ to open); a portfolio › Projects › portfolio-site.md bar under the tabs shows the active file’s path, and clicking a folder crumb reveals it in the tree.
  • Context menus — right‑click a tree row for Open / Copy Path / Copy Name / Copy Link, or a tab for Close / Close Others / Close All plus the copy actions; ↑/↓ and ↵ work too.
  • Notification balloons — IntelliJ‑style toasts in the bottom‑right: an “Indexing finished” / “Build succeeded” pair on load, plus a confirmation whenever a context‑menu copy runs. Hover to hold; click × to dismiss.
  • Shortcuts cheat‑sheet — F1 or ? opens a grouped list of every key the shell understands (labels adapt to ⌘ vs Ctrl).
  • Responsive drawer — below ~640px the Project / Structure panel slides in over the editor as a drawer with a tap‑to‑dismiss scrim; opening a file closes it, so the editor always gets the full width.
  • Resume.pdf — a tree entry that opens an embedded document viewer (an iframe onto a standalone /resume page built from the resume fragment), with Print / Save as PDF and Open in new tab.
  • Persistent layout — open tabs, the active file, tree state, panel sizes and the terminal all survive a refresh; every file is deep‑linkable with a #/Experience.md hash, and browser back/forward walk your open history.

How it works

  • The server renders the project tree from a ProjectStructure bean.
  • Opening a file fetch()es /content?path=…, which returns a Thymeleaf fragment that gets injected into a cached editor pane.
  • Open tabs, order, the active file, folder collapse state and panel width all live in localStorage; deep links use the URL hash (#/Path/file.md), with legacy ?file= links migrated on load.
  • Tabs drag to reorder, close on middle-click or Ctrl/Cmd+W, and the gutter line numbers are generated to match content height.

Ideas still on the list
