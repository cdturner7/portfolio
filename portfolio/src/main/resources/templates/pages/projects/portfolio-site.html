portfolio-site

This website. A portfolio that renders itself as the IntelliJ IDEA UI — project tree, editor tabs, gutter, status bar and all — because a plain landing page felt like a missed opportunity.

Stack

  • Spring Boot 3.5 / Java 21, built with Maven.
  • Thymeleaf with the layout dialect for the non-IDE surfaces.
  • A hand-rolled vanilla JavaScript shell — no framework, no jQuery.
  • One CSS file approximating the IntelliJ "New UI" dark theme.

Features

  • Search Everywhere — press Shift twice for a fuzzy file‑and‑action finder; Ctrl/Cmd+Shift+A scopes it to actions.
  • Terminal — a bottom tool window (Alt+F12) that types back: help, ls, cat, open, git log, resume and more, with ↑/↓ history.
  • Syntax highlighting — a small hand‑rolled tokeniser colours the JSON and code “files” at runtime.
  • Structure view — the left dock switches (Alt+7) to an outline of the open file’s headings; click one to jump to it.
  • Settings dialog (Ctrl+Alt+S) — switch theme (Darcula / IntelliJ Light / high contrast), editor font size and line height, and a presentation mode that strips the chrome down to the editor.
  • Editor tabs — drag to reorder, middle‑click or Ctrl/Cmd+W to close, Ctrl/Cmd+Shift+←/→ to cycle.
  • Persistent layout — open tabs, the active file, tree state, panel sizes and the terminal all survive a refresh; every file is deep‑linkable with ?file=.

How it works

  • The server renders the project tree from a ProjectStructure bean.
  • Opening a file fetch()es /content?path=…, which returns a Thymeleaf fragment that gets injected into a cached editor pane.
  • Open tabs, order, the active file, folder collapse state and panel width all live in localStorage; deep links use ?file=.
  • Tabs drag to reorder, close on middle-click or Ctrl/Cmd+W, and the gutter line numbers are generated to match content height.

Ideas still on the list
