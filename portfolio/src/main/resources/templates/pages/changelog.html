Changelog

Notable changes to this site, newest first. Dates are commit dates.

2026-09-03

  • SEO — Open Graph / Twitter-card meta, a canonical link, and robots.txt / sitemap.xml off the live host; /og.png is a 1200×630 share card drawn with Java 2D and cached.
  • Experience.md and Education.md entries carry dated headers and tech tags.
  • Now.md — a /now + /uses page (current focus + tools).
  • On-theme extras: CHANGELOG.md, dependencies.json in the tree viewer, and a shields-style deploy badge on the README.
  • notes/ folder with three build write-ups (IDE shell, JSON tree, hash routing).
  • Contact.md gains a working form — composes a mailto:, with a copy-to-clipboard fallback.
  • Skills.json is now real JSON rendered as a collapsible tree with per-skill proficiency.
  • Resume.pdf tree entry — an embedded document viewer over a standalone /resume page, with Print / Save as PDF.

2026-09-02

  • Routing moved to the URL hash (#/Experience.md); browser back/forward now walk your open-file history.
  • Mobile fallback — below ~640px the Project panel becomes a slide-in drawer.
  • Keyboard-shortcuts cheat-sheet (F1 / ?).
  • IntelliJ-style notification balloons, including an “indexing / build” pair on load.
  • Bottom tool window is tabbed: Problems / TODO / Git log / Terminal.
  • Right-click context menus on tree rows and tabs.
  • Recent Files popup (Ctrl+E) and a breadcrumb bar.
  • Live caret tracking, current-line highlight, and Go to line (Ctrl+G).

2026-09-01

  • Settings dialog — theme, editor font size, line height, presentation mode.
  • Structure tool window (Alt+7).
  • Terminal bottom tool window that types back.
  • Client-side syntax highlighting for the code panes.
  • TODO backlog page and Search Everywhere (double-Shift).
  • Shipped work tracked in a Features list instead of a “Done” section.

2026-08-26 – 27

  • Reskinned the whole site as the IntelliJ IDEA “New UI” dark theme.
  • Added Google Cloud Run deployment (multi-stage Dockerfile, scale-to-zero).
  • Upgraded to Spring Boot 4.1.1; removed an earlier stock-quote feature.

2024

  • Earlier lives of the site: a first IDE-homepage attempt with a draggable mini-map, some three.js experiments, and the original Spring Boot project scaffold.

The running list of what's next lives in TODO.md.
