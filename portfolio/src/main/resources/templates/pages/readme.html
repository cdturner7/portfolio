About this build

A Spring Boot 4.1 app (Java 21) serving Thymeleaf fragments over a vanilla-JS editor shell. Each "file" is a fragment fetched on demand; open tabs, layout, and the active file are kept in localStorage, so a refresh drops you back where you were. Every file is also deep-linkable with a #/ URL hash, and browser back/forward walk your history.

Tip: Alt + W closes the current tab (middle-click a tab works too). Alt + 1 toggles the project panel. The gear icon resets the layout.
