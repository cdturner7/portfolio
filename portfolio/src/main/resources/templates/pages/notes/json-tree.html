A collapsible JSON tree in ~70 lines, no library

Skills.json in the tree is real JSON rendered as an IntelliJ‑style folding tree. No editor component, no JSON.stringify with a replacer — just a small recursive HTML builder.

Ship the data as data

The fragment carries the actual object in a script tag the browser will not execute, and ide.js reads its text and parses it: 

<script type="application/json" id="skills-json">
{ "categories": { "languages": [ { "name": "Java", "level": "advanced" } ] } }
</script>

One recursive builder

jtBuild(key, value, depth) returns an HTML string. Primitives become a coloured <span>. Objects and arrays become a .jt-node with a clickable header row (open bracket + child count), a .jt-children block, and a closing row. A small jtIsFlat() check renders short all‑primitive objects like { "name": "Java", "level": "advanced" } inline on one line, which is what keeps the skills list readable.

Folding is a class, not a <details>

Collapsing is entirely CSS. A click toggles .collapsed on the node; the rest is two rules: 

.jt-node.collapsed > .jt-children,
.jt-node.collapsed > .jt-close { display: none; }
.jt-node.collapsed > .jt-row .jt-preview { display: inline; }  /* the " ... }" hint */

Nodes at depth ≥ 2 (the per‑category arrays) get .collapsed from the start, so the file opens as a tidy list of category names. “Expand all” just walks .jt-node and clears the class.

Colours reuse the same --syn-* CSS variables as the code highlighter, so the tree matches every theme for free.
